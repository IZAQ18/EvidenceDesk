# Closed-pilot validation

The free EvidenceDesk deployment is a protected product demonstration, not a production service.
Its purpose is to learn whether real reviewers can complete the citation-first workflow before
money is spent on infrastructure or acquisition.

## Recruit a small cohort

Invite five to ten reviewers individually. Share the pilot URL and access code privately, rotate
the shared code after the cohort, and never place it in a public post. Reviewers must use only the
fictional Northstar documents already supplied by the application. Do not collect or upload
personal, confidential, client, legal, medical, financial, or regulated information.

## Five-minute walkthrough

The **Pilot** view records progress locally in the reviewer's browser while they:

1. connect to the fictional evidence workspace;
2. obtain a grounded answer to an annual-leave question;
3. open and inspect the supporting citation;
4. ask an unsupported question and observe a safe refusal; and
5. rate an answer using the structured quality categories.

The final scorecard asks for ease, citation trust, usefulness, return intent, and two short comments.
It deliberately does not request a name or email. Free-text comments must not contain personal or
sensitive information.

## Decision signals

The administrator Insights view reports only aggregate pilot scores alongside answer feedback.
Use the first cohort to answer four questions:

- Can at least four of five reviewers finish the trust loop without live help?
- Do citations increase trust, rather than simply making the interface look technical?
- Which document questions fail repeatedly?
- Would reviewers return with a real, approved document set?

Do not treat a small synthetic pilot as proof of product-market fit, enterprise readiness, or answer
accuracy on customer documents. Before a paid pilot, create a customer-specific, human-reviewed
evaluation set and agree on success thresholds.

## Data limitation

Pilot reviews are tenant-scoped, included in administrator workspace exports, and removed when an
owned workspace is deleted. The free Render deployment uses ephemeral storage, so reviews may be
lost on restart or redeploy. Copy only aggregate, non-sensitive findings into the product decision
log after each cohort.
